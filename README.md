## My Projects 🚀

### Neotic — Visual AI Reasoning & RAG Platform 🤖

An explainable AI platform that transforms LLM reasoning into interactive visual graphs while supporting context-aware document querying through a Retrieval-Augmented Generation pipeline.

**Tech:** Next.js, FastAPI, Python, LangChain, React Flow, Firebase

---

### CareerCraft — AI-Driven Career Recommendation Platform 💼

An AI-powered career platform that generates personalized tech roadmaps, skill assessments, resume assistance, mock interviews, and role-based job recommendations.

**Tech:** React, Vite, Node.js, Google Gemini API, RapidAPI

---

### Road Damage Detection & Geospatial Monitoring 🛣️

A computer vision platform that detects potholes and road cracks from dashcam footage and maps detected hazards using GPS and geospatial visualization.

**Tech:** Python, YOLOv8, OpenCV, Streamlit, PyDeck, GPS Data
